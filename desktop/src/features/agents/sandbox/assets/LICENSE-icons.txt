Icon provenance for the sandbox workspace dock
(desktop/src/features/agents/sandbox/sandboxDockIcons.tsx)
================================================================

This directory's icons were chosen to avoid any GPL-licensed icon theme
(e.g. Papirus), since block/buzz is licensed Apache-2.0 and copyleft assets
are not acceptable here. Every icon below is either vendored from a
permissively-licensed upstream with its exact source recorded, or original
artwork authored for this project.

--------------------------------------------------------------------------
1. Browser (BrowserDockIcon)

  Source:  chromium-product-logo.svg, in this directory
  Origin:  The Chromium Authors, chrome/app/theme/chromium/product_logo.svg
  URL:     https://chromium.googlesource.com/chromium/src/+/main/chrome/app/theme/chromium/product_logo.svg
  License: BSD-3-Clause (Chromium's top-level LICENSE:
           https://chromium.googlesource.com/chromium/src/+/main/LICENSE)
  Notes:   Fetched verbatim, unmodified, via the file's Git blob content at
           the above URL. Chosen deliberately over the Google Chrome
           trademarked logo: the sandbox's Browser view runs Debian's
           `chromium` package (see Dockerfile.sprig-desktop), so this is
           the actual, correctly-branded mark for what the icon opens.
           BSD-3-Clause is compatible with this repo's Apache-2.0 license.

--------------------------------------------------------------------------
2. Files (FilesDockIcon)
3. Terminal (TerminalDockIcon)
4. Computer (ComputerDockIcon)

  Origin:  Original artwork, authored for block/buzz.
  License: Apache-2.0 (this repository's license — no separate grant needed).
  Notes:   Hand-drawn inline SVGs in the visual style of flat, front-facing,
           two-tone-gradient desktop icon themes (e.g. Papirus) — rounded
           folder/tile silhouettes, subtle top-edge gloss, flat glyphs — but
           are not copies, traces, or derivatives of any specific theme's
           files. No GPL or other copyleft source was viewed, referenced, or
           used as a basis while drawing these; the aesthetic (flat,
           two-tone, rounded-rect) is a generic, uncopyrightable style
           shared across many icon sets, not any one theme's expression of
           it. Authored directly in sandboxDockIcons.tsx as React
           components, not as standalone SVG files, since they need no
           external asset — see that file's own doc comments per icon.
